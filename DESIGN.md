Документ 3: DESIGN.md (UI/UX & Design System Specification)
1. Философия дизайна и Anti-Slop Манифест
Интерфейс проектируется как профессиональный инженерный инструмент (в духе Cursor, Linear, Vercel и аппаратных пультов Teenage Engineering). Главная цель — тактильная точность, визуальная тишина и фокус на тексте.

Строгие запреты (Zero AI-Slop Policy):

Никаких фиолетово-розовых и циановых градиентов, «магических» звездочек (✨) на каждом шагу и неоновых свечений (box-shadow: 0 0 20px).

Никаких размытых полупрозрачных карточек в стиле дешевого glassmorphism поверх цветных пятен.

Никаких пухлых скруглений (16px+) и мультяшных иконок.

Разделение контента строится исключительно за счет жесткой модульной сетки (1px solid), контраста чистого текста и выверенной типографики (Гротеск + Моноширинный шрифт).

2. Цветовая система и Динамические акценты (Color Tokens)
Базовая палитра — глубокий нейтральный графит и уголь с нулевым содержанием синего подтона (True Neutral Dark).

2.1. Базовые поверхности и текст (CSS Variables)
CSS
:root {
  /* Surfaces (Угольно-графитовая база) */
  --bg-canvas: #090909;         /* Основной фон страницы */
  --bg-surface-1: #111111;      /* Фон контейнера ввода и карточек превью */
  --bg-surface-2: #171717;      /* Hover-состояния, плашки тегов, неактивные табы */
  --bg-surface-3: #202020;      /* Активные контролы, выделенные блоки */

  /* Borders (Инженерная сетка 1px) */
  --border-subtle: #1F1F1F;     /* Внутренние разделители секций */
  --border-default: #2A2A2A;    /* Основные контуры панелей и карточек */
  --border-strong: #3E3E3E;     /* Рамка при наведении (hover) */

  /* Typography */
  --text-primary: #F2F2F2;      /* Основной текст поста и заголовки */
  --text-secondary: #999999;    /* Вторичный интерфейс, подписи */
  --text-muted: #555555;        /* Плейсхолдеры, счетчики символов, мета-инфо */

  /* Geometry */
  --radius-sharp: 0px;          /* Стыки внутри сетки */
  --radius-xs: 2px;             /* Бейджи, пилюли тегов, внутренние кнопки */
  --radius-sm: 4px;             /* Внешние контейнеры, кнопки, поля ввода */
}
2.2. Динамический акцент платформы (data-platform)
При переключении соцсети корневой контейнер меняет атрибут data-platform="telegram | youtube | instagram". Акцент используется дозированно: только для активного таба платформы, рамки фокуса поля ввода, индикатора стриминга и вспышки при копировании.

CSS
/* Telegram: Сдержанный технический стальной синий */
[data-platform="telegram"] {
  --accent-primary: #3B82F6;
  --accent-muted: rgba(59, 130, 246, 0.12);
  --accent-border: rgba(59, 130, 246, 0.45);
}

/* YouTube: Индустриальный сигнальный красный */
[data-platform="youtube"] {
  --accent-primary: #EF4444;
  --accent-muted: rgba(239, 68, 68, 0.12);
  --accent-border: rgba(239, 68, 68, 0.45);
}

/* Instagram: Теплый янтарный / терракотовый (без попсового градиента) */
[data-platform="instagram"] {
  --accent-primary: #F59E0B;
  --accent-muted: rgba(245, 158, 11, 0.12);
  --accent-border: rgba(245, 158, 11, 0.45);
}
3. Типографика (Typography Scale)
Контраст двух гарнитур создает ощущение профессионального терминала и редактора кода:

--font-sans: 'Geist', 'Inter', -apple-system, sans-serif — для текста постов, заголовков и ввода. Обеспечивает эталонную читаемость кириллицы.

--font-mono: 'JetBrains Mono', 'Geist Mono', monospace — для системных меток ([TITLE], [CTA], [TAGS]), таймкодов, счетчиков символов (412 CHARS), хэштегов и кнопок действий.

Правила набора:

Межстрочный интервал (Line-height): 1.55 для основного текста поста (как в нативных клиентах соцсетей), 1.2 для заголовков.

Системные метки (Mono Labels): Размер 11px, uppercase, letter-spacing: 0.06em, цвет --text-muted.

4. Компоновка и Сетка (Focused Single-Column Layout)
Весь интерфейс выстроен вокруг центральной вертикальной оси (максимальная ширина рабочей зоны 720px, выравнивание по центру экрана). По краям рабочей зоны могут проходить сквозные вертикальные направляющие линии 1px solid var(--border-subtle) от верха до низа вьюпорта (эффект чертежного листа).

4.1. Верхняя техническая панель (Top Bar — Высота 48px)
Разделена нижней линией 1px solid var(--border-default).

Слева: Строгий логотип/название в моноширинном шрифте (CONTENT_ENGINE // v1.0) и индикатор статуса API (зеленая точка 4x4px + GEMINI-2.5-FLASH).

Справа: Кнопка открытия истории [ ИСТОРИЯ (14) ] с хоткеем ⌘H.

4.2. Пульт ввода (Command Console — Сверху по центру)
Единый монолитный блок с рамкой 1px solid var(--border-default) и скруглением 4px, разделенный внутри тонкими линиями на 3 яруса:

Ярус 1 (Селектор платформы): Три сегментированные кнопки во всю ширину верхней грани (TELEGRAM | YOUTUBE | INSTAGRAM). Активная кнопка заливается --accent-muted, получает нижнюю границу 2px solid var(--accent-primary) и моноширинный маркер [●].

Ярус 2 (Поле ввода): Чистый textarea на фоне --bg-surface-1, без скроллбаров (авто-рост по высоте от 96px до 240px). В правом нижнем углу поля — моноширинный счетчик символов и токенов.

Ярус 3 (Полоса прегенерации и запуска):

При вводе текста или по клику на [УТОЧНИТЬ УГОЛ] под полем плавно раскрывается тонкая секция с 3 тегами прегенерации (например: + Кейс из практики, + Разбор ошибки, + Прямой оффер). Клик по тегу включает его в промпт (рамка становится --accent-border).

Справа внизу — главная кнопка запуска [ СГЕНЕРИРОВАТЬ ↵ ] (фон --text-primary, текст #090909, при ховере заливка --accent-primary).

4.3. Боковой дровер истории (Slide-over History Drawer)
Выезжает справа поверх холста (width: 400px, background: var(--bg-surface-1), левая граница 1px solid var(--border-default)).

Внутри: строка быстрого поиска, фильтр по платформам (ALL / TG / YT / IG) и плотный список прошлых генераций с датой в JetBrains Mono, темой и кнопкой мгновенного восстановления на главный экран.

5. Отображение результатов и Превью реального поста
Под пультом ввода разворачивается секция результатов. Пользователь может переключаться между 3 сгенерированными вариантами через горизонтальную панель вкладок (Tabs) над карточкой либо просматривать их вертикальной лентой (переключатель вида [ ТАБЫ | ЛЕНТА ] в правом верхнем углу секции результатов).

5.1. Дизайн карточки «Превью реального поста»
Карточка выглядит как аутентичный макет поста в конкретной соцсети, но вписанный в строгую эстетику нашего приложения (border: 1px solid var(--border-default), border-radius: 4px, background: var(--bg-surface-1)):

Шапка карточки (Header):

Слева: Моноширинный бейдж угла подачи (например, ВАРИАНТ 01 // ЭКСПЕРТНЫЙ КЕЙС) и мимикрия под шапку соцсети (для Telegram — название канала и время 14:32, для YouTube — превью-рамка 16:9 с заголовком ролика под ней, для Instagram — компактная шапка профиля и иконка Reels/Carousel).

Справа: Главная кнопка [ СКОПИРОВАТЬ ВСЁ ].

Внутренняя структура поста (4 интерактивных блока):
Текст внутри карточки читается как единый живой пост в ленте, но при наведении курсора на любую из 4 логических зон (Заголовок, Основной текст, CTA, Хэштеги) вокруг конкретной зоны проявляется тонкая пунктирная или сплошная техническая рамка 1px solid var(--border-strong) с крошечной меткой в правом верхнем углу [ TITLE · КОПИРОВАТЬ ], [ BODY · КОПИРОВАТЬ ], [ CTA · КОПИРОВАТЬ ], [ TAGS · КОПИРОВАТЬ ].

Заголовок: Крупный жирный гротеск (18px, font-weight: 600), визуально отделенный воздухом.

Основной текст: Форматированный текст с сохранением абзацев, списков и тире (15px, цвет --text-primary).

Блок CTA: Отделен тонкой линией 1px dashed var(--border-subtle) или левым акцентным бордером 2px solid var(--accent-primary).

Хэштеги: Набраны шрифтом JetBrains Mono (13px, цвет --accent-primary), каждый тег можно скопировать отдельно или всю строку сразу.

6. Физика анимаций, Стриминг и Микровзаимодействия (Motion Design)
Все анимации работают на физике пружин (Spring Physics через framer-motion или CSS cubic-bezier(0.22, 1, 0.36, 1)), сочетая инженерную четкость с плавной кинетикой.

6.1. Плавное проявление слов при стриминге (Word-by-Word Blur Fade-In)
Вместо дерганого появления букв или мигающего курсора новые чанки текста от Gemini API оборачиваются в <span> по словам и проявляются с мягким оптическим эффектом:

CSS
@keyframes tokenReveal {
  0% {
    opacity: 0;
    filter: blur(4px);
    transform: translateY(2px);
  }
  100% {
    opacity: 1;
    filter: blur(0px);
    transform: translateY(0);
  }
}

.streaming-word {
  display: inline;
  animation: tokenReveal 240ms cubic-bezier(0.22, 1, 0.36, 1) forwards;
}
Это дает эффект того, что последние 2–3 слова в потоке мягко фокусируются из легкой дымки прямо в четкий текст.

6.2. Плавная физика высоты карточки (Smooth Height Auto-Resize)
По мере того как Gemini дописывает абзацы, карточка не «прыгает» рывками по пикселям, а плавно раздвигается вниз с помощью ResizeObserver + framer-motion (layout="position", transition={{ type: "spring", stiffness: 280, damping: 28 }}).

6.3. Тактильный фидбек копирования в 1 клик (300ms Border Flash + Button Morph)
При клике на кнопку [ СКОПИРОВАТЬ ВСЁ ] или на отдельный блок ([ CTA ], [ BODY ]):

Вспышка рамки (Target Highlight): Контур именно того блока, который был скопирован (или всей карточки целиком), мгновенно вспыхивает цветом --accent-primary с легкой внутренней заливкой --accent-muted и плавно гаснет обратно в --border-default ровно за 300ms. Глаз безошибочно фиксирует площадь скопированного контента.

Морфинг кнопки: Текст внутри кнопки плавно меняется по ширине (через layout анимацию контейнера кнопки) с [ СКОПИРОВАТЬ ] на [ СКОПИРОВАНО ✓ ], меняя цвет текста на --accent-primary. Через 1500ms кнопка мягко возвращается в исходное состояние.

7. Состояния интерфейса (UI States)
Empty State (До первой генерации): Никаких картинок. Под пультом ввода расположена тонкая техническая сетка с 3 кликабельными пресетами-примерами в моноширинном стиле (например: [ ПРИМЕР 01: Анонс IT-курса в Telegram ], [ ПРИМЕР 02: Сценарий и описание Reels для сервиса ]).

Pre-generation State: В нижней части пульта ввода пробегает тонкая линия-индикатор 1px цвета --accent-primary, после чего с пружинной физикой выезжают 3 кнопки-тега с предложенными углами подачи.

Error State: Строгая плашка с темно-красным бордером #7F1D1D, моноширинным кодом ошибки [ERR_STREAM_INTERRUPTED] и кнопкой [ ПОВТОРИТЬ ЗАПРОС ].
